# Ruddix Studio site

A scroll-driven, ink-style WebGL site for Ruddix Studio. The homepage story follows the studio workflow (Idea, Design, Build, Automate, Launch, Scale) with a 3D cursor as the main character. Each scene dives into an object and the next one bursts out of it. A separate Portfolio page holds 4 featured projects and a link to the Notion demo library.

## Run

```bash
python serve.py
```

`serve.py` serves `public/` with caching turned off, so after an edit the browser always loads the latest CSS and JS (plain `python -m http.server` lets the browser keep stale files).

Open http://localhost:5181 (no build step; Three.js, GSAP and Lenis load from jsDelivr).

## Deploy (Vercel)

Pages use clean addresses (`/portfolio`, not `/portfolio.html`): `vercel.json` sets `cleanUrls`, and `serve.py` does the same locally.

Import the GitHub repo in Vercel and deploy with the defaults. `vercel.json` tells it there is no build or install step and to serve `public/` as a static site.

## Edit content

Everything you'll want to change is in **`public/js/content.js`**:

| What | Where |
|---|---|
| Name, tagline, email, booking link, socials, **Notion link** | `BRAND` |
| Story captions, scene lengths, hold-button labels, step names | `STORY` |
| Launch counters, hours-saved counter | `METRICS`, `SAVED` |
| Manifesto, services (+ motion graphics add-on), process cards | `MANIFESTO`, `SERVICES`, `EXTRA_SERVICE`, `PROCESS` |
| **Portfolio projects** (name, type, result, tags, year, link, colour, 3D object) | `PROJECTS` |

Values marked `PLACEHOLDER` are made up (project names, links, email). Replace them before launch.

The logo is a placeholder SVG `<symbol id="emblem">` in `index.html` and `portfolio.html`.

## How it's built

| Path | What it is |
|---|---|
| `public/js/story.js` | Scroll engine: pinned scenes, dive-through transitions, comic panels, captions, hold button, step label |
| `public/js/scenes/intro.js` | Interactive hero: dry-brush ink strokes that part around the pointer, the title printed by a shader (letterpress edges, 8 fps boil), a pointer wake that reveals the letters' blueprint construction and spatters ink, then a caret that opens onto the train scene. The `<h1>` stays in the page (invisible) for screen readers and search |
| `public/js/scenes/workflow-a.js` | 01 Idea (pencil draws the site on a giant sketchbook), 02 Design (blocks pop up grey; the cursor paints them from a palette) |
| `public/js/scenes/workflow-b.js` | 03 Build (the sketch on an empty frame; blocks snap onto it; hold to speed up), 04 Automate (isometric blueprint machine: hopper, conveyor, gears, press, bins, live monitor) |
| `public/js/scenes/workflow-c.js` | 05 Launch (dawn side-scroll: parallax skyline, WE'RE LIVE sign, paper plane with the cursor riding), 06 Scale (one site card deals out into an R; a swarm of user cursors clicks it) |
| `public/js/scenes/common.js` | Cursor, pencil, ruled paper, layout drawing, paper plane, Blender-object inking |
| `public/js/stage.js` | 3D objects drawn inside HTML boxes (`data-view="icon:web"`) on the homepage and Portfolio |
| `public/js/ink.js` | Ink shader: flat lit colour, hatched mid-tones, inked shadows, outlines, glass rim |
| `public/js/ui.js` | Scroll reveals, page wipe between Home and Portfolio, smooth scroll |
| `blender/*.py` | Rebuild the 3D objects headless: `blender --background --factory-startup --python build_icons.py -- blender` (also `build_tools.py`) |
| `public/textures/` | Ink shader textures (hatch lines, grain), generated by `python tools/make_textures.py` (needs numpy and Pillow) |

## Entry screen

Visitors land on a full-screen menu (Story / Portfolio / Contact). Picking one shrinks the whole screen into the navbar pill in the top right, then starts the story, wipes to the Portfolio page, or glides to Contact. It's skipped for deep links (`#contact`, `?at=`). Code: `public/js/entry.js`.

## Demo library (Portfolio page)

The "Pick a design you like" section lists ready-made demo sites with filters, a screenshot of each, "I want this design" (opens a pre-filled email to the studio) and "View live site". It opens with one featured design plus two rows, mixing the business types, then "Show more" adds 12 at a time. The ~48 niches are grouped into 10 simple filter chips (Home Services, Health & Fitness, Food & Drink...); each card still shows its exact niche.

- **The list** is `tools/notion_list.txt` (a niche line, then its URLs, copied from the Notion page). `python tools/build_demos.py` turns it into `public/demos/demos.json`, naming each demo from its page title and sorting niches into chip groups (`GROUPS` in the script). It also holds `SKIP` (listed demos whose site returns 404) and `WAITS` (slow intros).
- **Screenshots:** `node tools/shoot_demos.mjs` captures any demo with no thumbnail yet using the installed Chrome (`--all` re-shoots everything, or pass an id). If a demo is caught mid-animation, add it to `WAITS` in `build_demos.py` and re-shoot it.
- Code: `public/js/demos.js`, styles under "Demo library" in `css/style.css`.

## Sound

One background track, no sound effects: a calm CC0 piano piece (`public/music/theme.mp3`, credits in `public/music/CREDITS.txt`, linked from the footer). It loops quietly and is on by default. Browsers only allow audio after a click or key press, so it starts with the entry-screen pick (which has a Sound on/off pill) or the first click anywhere. The bars button in the bottom right mutes it, and the choice is remembered. Code: `public/js/audio.js`; to change the music, replace `theme.mp3`.

## Colours

One palette: crimson red, cream paper and ink. The CSS variables are at the top of `css/style.css`, and the 3D/shader palette is `PALETTE` in `public/js/ink.js`.

## Review links

`?at=idea:0.5` jumps to a story scene at a given progress, `?at=#services` to a section.
